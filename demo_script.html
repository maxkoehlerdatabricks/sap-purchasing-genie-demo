1 · The business story

An automotive OEM buys thousands of parts from hundreds of suppliers. If a critical part is single-sourced and that one supplier has a delivery-risk flag, the line can stop. Today that analysis lives in SAP and needs specialist access. We've lifted the purchasing data into Databricks so any analyst can ask these questions in plain English.

We answer two core capabilities: (1) detect materials lacking a multi-sourcing strategy, and (2) detect materials exposed to suppliers with a delivery-risk flag — plus nine more related questions, all from a consolidated gold layer.

2 · The data model — 13 raw → 5 gold

Everything is simulated from a deterministic seed, so the demo is fully reproducible on a blank workspace. Thirteen SAP-style raw tables are consolidated by five dependency-ordered workflows into five analysis-ready gold tables.

Deliberate, meaningful gaps are baked in: some materials are single-sourced, some suppliers carry an active delivery-risk flag, some quotas exceed 80% to one vendor, some quotas are NULL (source-listed but not quota-split), and some POs were placed while risk was active. Every business question returns a real answer.

3 · Governed semantics

Parameterized trusted SQL functions

The nuanced logic is encapsulated as governed, parameterized UC functions — a certified answer Genie can call instead of guessing SQL.

-- "materials with no multi-sourcing strategy" is a one-liner:
SELECT * FROM purchasing_demo.materials_without_multisourcing(2);

-- one vendor holding > 80% of quota:
SELECT * FROM purchasing_demo.quota_concentration(80);

-- on-time delivery rate per supplier, last 12 months:
SELECT * FROM purchasing_demo.otd_rate_per_supplier(12);

UC Metric Views

Four governed metric views define the KPIs once (sourcing coverage, supplier risk, delivery performance, price analytics) — reused identically by Genie, the App and any dashboard.

SELECT `Supplier`, MEASURE(`OTD Rate`), MEASURE(`Deliveries`)
FROM purchasing_demo.mv_delivery_performance
GROUP BY ALL ORDER BY 2 ASC;

Value dictionary

VALUE_DICTIONARY maps cryptic SAP codes to plain language so an analyst can say "raw materials" and Genie knows that means MTART='ROH'.

4 · Genie spaces — natural-language sourcing risk

Two domain-split spaces, each configured with all instruction types (general/text notes first, then joins, then SQL examples, then certified functions):

SpaceCovers
Sourcing & Supplier RiskMulti-sourcing, single-sourcing, supplier risk, purchasing blocks, quota
Purchase Order AnalyticsOn-time delivery, price variance, spend, orders under active risk
1Open Space 1. Ask: "Which materials have no multi-sourcing strategy?"
Notice Genie doesn't hand-write SQL — it calls our certified function materials_without_multisourcing(min_vendors => 2). That's a trusted, governed answer.
2Ask the flagship risk question: "Which materials are single-sourced and their sole supplier has a delivery-risk flag?" → returns the highest-priority supply-continuity risks with risk scores.
3Switch to Space 2. Ask: "What is the on-time delivery rate per supplier over the last 12 months?"
Instruction ordering recommendation (in the genie_instructions_*.md files): add general/text instructions first (highest ROI — vocabulary + the "valid vendor" and time-slice rules), then joins, then SQL examples, then certified functions.

5 · Agent Bricks Multi-Agent Supervisor

The two Genie spaces sit behind a single Multi-Agent Supervisor serving endpoint. It routes each question to the right domain — or consults both for cross-domain questions.

▶Query the endpoint (Responses API):
POST /serving-endpoints/mas-655dcd32-endpoint/invocations
{ "input": [{ "role": "user",
    "content": "Did we place POs with single-sourced risky suppliers?" }] }
Watch the trace: the supervisor emits a function_call to Sourcing_Supplier_Risk (and/or Purchase_Order_Analytics), each of which runs its Genie space, then the supervisor combines the answer.

6 · The App — visualizations + chat

A Databricks App (React + FastAPI) with two tabs:

  • Visualizations — KPI cards (materials without multi-sourcing, single-sourced & risky, suppliers at risk, overall OTD) and four charts, all fed by the metric views and trusted functions via the serverless SQL warehouse.
  • Chat (MAS) — the same natural-language experience as Genie, but through the supervisor endpoint, with the routed agent shown for each answer.
1Open the Visualizations tab — the KPI cards immediately quantify the sourcing risk (e.g. materials without multi-sourcing, single-sourced & risky).
2Open the Chat tab, click a sample question, and show the answer streaming back with the "routed to …" badge.

7 · Trust & accuracy — the benchmark

We ship a benchmark of representative questions (the 11 spec questions + extras), each with known-good SQL. The runner executes the known-good SQL and asks the MAS the natural-language question, then compares result signatures and prints an accuracy score.

On the reference dataset the MAS scores ~94–100% against the known-good answers — proving the natural-language layer is trustworthy, not a black box.
SELECT id, known_good, mas, match FROM purchasing_demo._BENCHMARK_RESULTS ORDER BY id;
