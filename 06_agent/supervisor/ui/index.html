SAP Purchasing Assistant

Ask a purchasing question in plain language. Choose how it should be answered.

How this assistant works

Supervisor mode

Built for SAP purchasing. It answers from our own data, not from the internet.

  1. You ask a question in plain language.
  2. The supervisor works out what you need. It passes the question to the right expert.
  3. There are two experts, called Genie Agents. Each knows one area:
    Sourcing & Supplier Risk: single sourcing, supplier risk, purchasing blocks, quotas, open mitigation cases.
    Purchase Order Analytics: on-time delivery, prices, spend, orders placed with risky suppliers.
  4. The expert looks up the answer in our SAP data. It uses agreed business definitions, for example what "on time" means.
  5. The supervisor puts the answer together and names its source.

If a question touches both areas, it asks both experts, one after the other.

Your question → Supervisor → Genie Agent(s) → governed SAP data → Answer

How it was built

The data team built the supervisor as code with the Databricks Agent Bricks CLI. It runs on Databricks. It only sees data it is allowed to see in Unity Catalog. Every question and answer is saved as a trace.

Normal mode

The same AI model, used like ChatGPT. It has no access to our data and knows none of our definitions. Use it for general questions, explanations or drafting an e-mail. It cannot know our suppliers or orders.

Tip: ask the same question in both modes and compare the answers.
