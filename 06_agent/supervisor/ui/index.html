Supervisor: the model with our context

Built for SAP purchasing. It answers from our own data, not from the internet.

  1. You ask a question in plain language.
  2. The supervisor splits it into smaller questions for the right experts.
  3. Two experts, called Genie Agents, each know one area:
    Sourcing & Supplier Risk: single sourcing, supplier risk, purchasing blocks, quotas, open mitigation cases.
    Purchase Order Analytics: on-time delivery, prices, spend, orders with risky suppliers.
  4. Each expert looks up the answer in our SAP data, using agreed business definitions, for example what "on time" means.
  5. The supervisor combines the answers and names its sources.
Your question→Supervisor→Genie Agents→SAP data→Answer

Under each answer you see the trace: which Genie Agent got which question.

How it was built

The data team built the supervisor as code with the Databricks Agent Bricks CLI. It runs on Databricks. It only sees data it is allowed to see in Unity Catalog. Every question and answer is also saved as a trace in MLflow.

Normal chat: the model without our context

The same AI model, …, used like ChatGPT. It gets no instructions, no tools and no access to our data. It can explain general ideas or draft an e-mail, but it cannot know our suppliers or orders.
